Genesys Cloud inbound paste (replaces the MAS "Stats / InCust SVC" page).
Copy the three widgets — External ASA, External SL, External LCW — into the
INBOUND box in one paste. Each widget has a Today column and a Current
interval column (the copy duplicates the value pair; only the first pair is
read).

Mapping used by the calculator:
  ASA          -> External ASA, Today value
  SVL IN       -> External SL, Today value
  LCW Interval -> External LCW, Current interval value
  SAFE         -> N/A (read from a separate tableau, filled in manually)
  Inbound trend-> N/A (not available from Genesys yet, filled in manually)

When the Current interval has no data yet (blank, "-", "--" or "N/A", or the
blank cell simply missing from the copy), ASA and SVL IN still use Today and
LCW Interval shows N/A — it never falls back to Today's max wait.

Expected output with the DEFAULT template (outbound fields depend on the MAS
outbound paste). The report layout is editable at runtime from the Calculator
view ("Report Template" panel) and stored server-side — no redeploy needed to
change wording. Placeholders {svlOut} {svlIn} {ack} {asa} {lcw} {safe}
{trendIn} {trendOut} are filled from the stats; everything else is literal text
you can edit (e.g. add "(Genesys)" back, or flip Coaching Open -> Closed).

You can also keep a LIBRARY of named layouts (e.g. "Week A - Night",
"Week B - Evening") and switch the active one from the panel's dropdown; the
built-in "Default" is always available and can't be edited or deleted. Note:
adding this feature required one clasp push + a New Version deployment; after
that, template/library edits take effect live with no further redeploy;
