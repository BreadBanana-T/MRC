Genesys Cloud roster paste (Red Flags → Sync Roster).

Export the "Agent Status Summary" view from Genesys Cloud Performance and paste
it whole — comma- or tab-separated both work, and the trailing status columns
(Logged In / On Queue / Idle / …) are ignored: this is a roster sync, not a
presence sync.

How the Skills cell is read (see CORE/GenesysRoster.gs):
  English / French          -> language: EN, FR, or BL when both are present
  SAM_Monit_Lv_<tier>       -> level:    Junior = 1, Regular = 2, Senior = 4
  SAM_Monit_Sk_<name>       -> skill:    Questions, Video, SmartWear, Escalation,
                                         BckMRC (= Back MRC), BTS, SME

Who counts in Red Flags:
  Regular / Senior          -> counted
  Junior                    -> NOT counted (still shown on the floor)
  language only, no Lv tag  -> NOT counted
  nothing attached          -> NOT counted
